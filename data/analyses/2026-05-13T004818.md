# Session 2026-05-13T004818 — multi-device rig validation + KOEO baseline

**Purpose:** first run of the coordinated Canable + ELM327 (+ NT510 later) test
plan. Validate the capture rig and grab a key-on/engine-off broadcast + PID
baseline before doing anything dynamic.

## Hardware / state

- **Canable** — knockoff USB-CAN-FD running the CANable2 slcan firmware,
  `/dev/ttyACM0`, opened by `scripts/record.py` at 500 kbps classic CAN. Opened
  in normal (`O`) mode: this adapter's firmware ignores the slcan `L`
  (listen-only) command — 0 frames in that mode — so it ACKs frames but the
  recorder never transmits a data frame (FR-02 invariant). On the OBD-II port
  via a splitter.
- **ELM327** — CH340 clone reporting `ELM327 v1.5`, `/dev/ttyUSB0` @ 38400 baud,
  MS/HS switch on **HS**, on the OBD-II splitter. Kept attached to WSL with
  `usbipd --auto-attach`.
- **NT510** — not in the loop for this run.
- Ignition: **key ON, engine OFF.** Battery ~12.4 V (ECM PID 42). Coolant ~53 °C
  (engine had been run recently and was cooling). No stored DTCs.

## What was captured

`data/sessions/2026-05-13T004818/` (gitignored): `frames.log` (candump, 9.7 MB),
`pids.jsonl` (210 KB), `manifest.json`. ~123 s. 0 parse errors, 0 reconnects,
0 dropped writes.

So 28 vehicle broadcast IDs + the diagnostic request/response pair from our own
ELM327. The 7DF/7E8 traffic on the sniff is the point: it lets the offline
cross-reference line up "ELM327 decoded RPM = X at time T" against the broadcast
byte that moved at the same T.

### OBD (`pids.jsonl`) — 2,448 readings, 306 each of 8 PIDs (~2.6 Hz/PID)

Last values, KOEO: RPM 0, ENGINE_LOAD 0 %, THROTTLE_POS 6.7 % (closed),
COOLANT_TEMP 53 °C, INTAKE_TEMP 42 °C (heat-soak drift up), CONTROL_MODULE_VOLTAGE
12.16 V. Two engine-off artifacts to ignore until the engine runs: **MAF 1.18 g/s**
(sensor zero-flow floor, not real airflow) and **TIMING_ADVANCE 63.5°** (garbage —
PID 0x0E is meaningless with the engine off).

### Clock alignment

`frames.log` and `pids.jsonl` both timestamp with `time.time()`; OBD starts ~4.5 s
after CAN (the ELM327 connect handshake) and both run to the same end time. Cross-
referenceable.

## Verdict

Rig is solid: Canable sniffs cleanly, the ELM327 polls and that traffic shows up
on the sniff, the supervised OBD thread connected and ran the whole window with no
reconnects, and all three output files were written. Next: run #2 — engine

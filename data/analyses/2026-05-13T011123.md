## Tag-order caveat

The running `guided_session.py` predated the protocol reorder (commit moving
`engine_start` ahead of the steering block), so `engine_start` is tagged at
~t=1778635442 — **after** the `steer_*` and `brake_*` tags. Whether the engine
was actually off during the steering test (heavy on this vehicle's hydraulic PS)
or already running with the tag fired late changes how the steering windows are
read — there's a cluster of state bytes flipping right around there. Worth
confirming, and a cleaner steering run should have the engine confirmed running.

## Byte-vs-tag differential — candidate signals

`tools/broadcast_signals.py` over the 15 tag windows.

**Steering — 0x002 (the ~100 Hz high-rate ID):** bytes 0 and 1 swing hard and
sweep their full 0–255 range during `steer_full_left`/`steer_full_right`/
`steer_center` and are pinned otherwise — looks like the 16-bit steering-angle
value. Byte 2 goes from ~0 to ~16–28 *only while the wheel is turning* — a
steering-rate / velocity candidate. Strongest steering-correlated ID by a wide
margin. (Caveat: the "pinned" value before steering (≈0xFFD6) differs from after
(≈0x002B), so the sensor reference may not be a simple absolute angle — confirm
against the NT510's ABS steering-angle readout in a follow-up run.)

**Brake — 0x29E:** byte 3 is 0 at rest and averages ~32 over the `brake_press`
window (i.e. ~64–128 during the firm presses, 0 between) — brake-pressure /
pedal-position candidate. Byte 7 sits at ~117 everywhere except `brake_press`
where it jumps to ~149 — a brake-active flag/counter.

**Cooling fan — 0x284 / 0x285 (mirror each other):** byte 6 jumps from ~127 to
~181 during the `nt510_fan_test_on` window and reverts at `_off`; byte 7 drops
~127→70 over the same window — fan duty/state. (Consistent with run #2, where
0x284/0x285 byte 6 also rose with throttle blips → it tracks engine load, which
fan duty follows.)

**State latches:** 0x231 b0/b3/b4 and 0x29E b0 (254→211), 0x625 b3 (157→29),
0x358 b3 (32→0), 0x002 b1 (255→0), 0x551 b3 (160→128), 0x002 b0 (~214→~43) all
flip in the steering/brake/engine-start region and don't revert — most likely
engine/ignition-state latches that fired around the engine start; they
partially contaminate the steering-window means. Disentangle from the time
series.

**Module map:** the 452 s `nt510_module_scan_start` window contains the NT510's
diagnostic request/response traffic to every module (distinct 7Ex-ish ID pairs
per module). Grepping `frames.log` in that window (or
`broadcast_signals --detail-ids`) gives the module → CAN-ID map.

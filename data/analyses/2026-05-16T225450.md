# Session 2026-05-16T225450 — NT510 cooling-fan active test

**Purpose:** pin the cooling-fan signal via an NT510 actuator test — the
one capability the read-only stack fundamentally lacks. NT510 commands the
fan; Canable records broadcast passively; we recover both the command
(on the wire) and the broadcast byte that reflects it.

## Method

NT510 plugged into the OBD-II port, Engine → Active Test → Cooling Fan.
Canable on the same bus recording **broadcast-only** (`record.py`,
listen mode — one active tester + one passive recorder, no contention,
no `0xC0` poller). Warm idle. Sequence: long OFF baseline → LOW → HIGH →
OFF, **twice** (operator-timed; the second cycle separates the commanded
fan from the ECM's own temp-driven fan control). `stop_recording.py`
clean stop (496,708 frames, 0 parse / 0 reconnect).

## Decoded NT510 command (on the wire, 0x7E0)

Nissan IO-control **service `0x30`**, two fan stages:

- `30 33 20 01 / 00` — channel `0x33` = **fan stage 1** (LOW), on/off
- `30 34 20 01 / 00` — channel `0x34` = **fan stage 2** (HIGH), on/off
- LOW = stage 1 only; HIGH = stage 1 + stage 2
- `30 33 11` / `30 34 11` = release control back to ECU (test exit)

Anchors (capture-relative): LOW≈147 s, HIGH≈177 s, OFF≈214 s.

## Broadcast binding — COOLING_FAN_1F9_0 (added to bindings.yaml, high)

`0x1F9` byte 0 (the same ~100 Hz ECM frame that carries RPM on bytes 2-3)
stepped, dead-stable, in lockstep with the commanded stages:

| state | 0x1F9:0 | bits |
|---|---|---|
| OFF | `0x20` | base |
| LOW | `0x60` | base \| `0x40` (stage 1) |
| HIGH | `0xE0` | base \| `0x40` \| `0x80` (stage 2) |

The broadcast bit pattern maps one-for-one onto the commanded stages, so
the actuator command and the passive reflection corroborate each other
independently. **Bit `0x40` = fan low, bit `0x80` = fan high.** Supersedes
the mistagged 2026-05-13T011123 fan attempt (the "clean redo" the
bindings IPDM note asked for).

**Anomaly value:** purely passive fan-fault detection — coolant climbing
while `0x1F9:0 & 0x80` never asserts → stage-2 fan not engaging.

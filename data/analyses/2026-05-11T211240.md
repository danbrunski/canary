## Key findings (10 new / promoted bindings)

### `0x002:1` — Gear/motion-state enum (HIGH confidence — NEW)

Cleanest enum-style signal in the data. Three values across all windows:

```
stationary states (engine off, idle, A/C on, p-brake, clutch in)  → 254
gear_reverse                                                        →  63 (0x3F)
coming_to_stop (forward driving)                                    → 102 (0x66)
```

Bit patterns suggest individual flags packed into the byte. Once Mode 01
PID `0x14` (or equivalent transmission state) ground truth is available,
this is the single most diagnostic byte — it tells the daemon "vehicle is
moving forward / reversing / stopped" without any decoding ambiguity.

### `0x625:1` — A/C compressor state (HIGH confidence — NEW)

One-event response to the `air_condition_on` tag:

```
all pre-AC windows  →   0 (compressor off)
air_condition_on    → 123 (instant jump)
parking_brake_off   → 128
clutch_in           → 128
gear_reverse        →  50 (compressor cycling under load)
coming_to_stop      →  49 (compressor cycling under load)
```

Useful for diagnostics: A/C button pressed but byte stays at 0 = compressor
or pressure switch failure.

### `0x625:3` — Power/ignition state (MEDIUM — NEW)

Three-state ignition tracker:
```
key_on_engine_off / pre-tags     → 157
engine_started (transitional)    →  52
all driving states               →  29
```
Mid-drive reversion to 157 would indicate the engine died. Strong anomaly-
detection input.

### `0x385:2-6` — Odometer/trip accumulator (MEDIUM — NEW)

Five contiguous bytes that are uniformly 0 across all stationary/reverse
windows, then all climb together during forward driving. Same pattern in
all five bytes = multi-byte accumulator. Best candidate for trip distance
or odometer ticks.

### `0x233:1` — Intake MAP (PROMOTED to HIGH from medium)

The new evidence is the A/C-load drop: `engine_started` mean is 74, A/C on
drops it to 49, releasing clutch (engine briefly higher rpm) spikes to 243.
That A/C-load response is textbook manifold absolute pressure behavior.
Cross-reference with Mode 01 PID `0x0B` when ELM327 arrives.

### `0x23D:6` — Throttle transient (PROMOTED to MEDIUM from hypothesized)

Two physical-action sessions now agree: ~0 at steady state, climbs with
throttle activity. The earlier NT510-screen-tagged session is now treated
as misattributed and ignored for confidence-grading.

to operating temperature. The trip ended before reaching thermostat-regulated
plateau (~90°C).

## Lessons learned

The tags here were excellent. Each represented a clear physical transition
on the vehicle that the ECM/BCM would respond to. Specifically valuable:

- **`air_condition_on`** isolated the A/C compressor byte perfectly
- **`engine_started`** caught the cranking transient state
- **`clutch_in` + `gear_reverse`** distinguished engine-on-stationary from
  about-to-move from actually-moving (clean separation in `0x002:1`)
- **`parking_brake_off`** showed which bytes are brake-state-dependent

The next drive should aim for similar physical-action diversity. Plus:
sustained highway cruise (long enough to overflow the multi-byte
accumulator and learn its scale), hard braking, sharp turns.

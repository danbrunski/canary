# Session 2026-05-16T231901 — NT510 cylinder power-balance test

**Purpose:** per-cylinder actuator ground truth — drive the NT510
power-balance (cylinder-cut) test across all 6 cylinders to (a) decode
how the ECM addresses individual cylinders and (b) hunt a per-cylinder
broadcast signal. Canable records broadcast passively.

## Method

NT510 → Engine → Active Test → Power Balance, **manual** per-cylinder
cut. Warm, stable idle, P/N, parking brake, A/C off. Per cylinder 1→6:
cut → hold ~5 s → restore → pause. Canable broadcast-only record;
`stop_recording.py` clean (511,125 frames, 0 parse / 0 reconnect).

(Mid-session the Canable dropped off WSL — `vhci_hcd: disconnect`,
usbipd timeout. Recovered by physical replug **plus** a fresh
`usbipd attach --wsl` on the host; a physical replug alone does not
restore the WSL forwarding and the busid changes. Recorder fail-fast
caught it cleanly — nothing captured, no engine stress wasted.)

## Decoded NT510 command (on the wire, 0x7E0)

Nissan IO-control **service `0x30`**, channel `0x0C`, sub `0x20`,
**cylinder selected by a bitmask byte**:

| bit | cyl | cmd t | RPM dip (from 0x1F9) |
|---|---|---|---|
| `0x01` | 1 | 85 s | 766 → **556** (−210) |
| `0x02` | 2 | 130 s | → 612 (−154) |
| `0x04` | 3 | 165 s | → 622 (−144) |
| `0x08` | 4 | 198 s | → 619 (−147) |
| `0x10` | 5 | 231 s | → 619 (−147) |
| `0x20` | 6 | 264 s | → 609 (−157) |

Plus `30 0C 01` (×174 — test-active keep-alive, held throughout) and
`30 0C 11` (×6 — restore after each cut). RPM dips line up exactly with
the command times (timing validated against broadcast `0x1F9` RPM).

## Result

**Engine healthy / balanced.** All six cylinders produce a comparable
RPM drop on cut. Cyl 1's deeper −210 (vs ~−150) is the expected
idle-controller artifact — the first, least-compensated cut — not a
strong/weak cylinder. This even 6-cylinder signature is a useful
"nominal" reference for misfire/contribution anomaly detection.

**Negative result (recorded so we don't re-hunt it): no clean
per-cylinder encoding on the broadcast bus.** A differential over the 6
precisely-anchored cut windows surfaced only known high-variance /
load-perturbation bytes (`0x551:1`, `0x2DE:4/5`, `0x29E:5`,
`0x284/0x285:6/7`, `0x1F9:3`) — these wobble because the engine runs
*rough* during any cut, reflecting generic RPM/load/airflow, not *which*
cylinder. Per-cylinder identity here is **diagnostic-only** (the `0x30`
bitmask command). Passive monitoring can detect rough-running but not
the offending cylinder without a Mode 22 misfire-counter DID (reachable
only via the `0xC0` session — see 2026-05-16T223328).

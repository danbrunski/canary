## Key findings

### Cleanest engine-running detection yet

`0x23D:6` (ECM_THROTTLE_TRANSIENT):
```
key_on_engine_off_warma:    8    (engine off baseline)
cranking:                 239    (jumps the instant the engine cranks)
driving:                   94    (active during throttle modulation)
stopped:                  240    (idle compensation activity)
```
The 8 → 239 jump at cranking confirms this is engine-running activity, not a
"set after diagnostics request" artifact. **Promoting from medium to HIGH
confidence.**

### Engine-state byte 0x002:1 — three-state encoding holds firm

```
all engine-off windows:    251    (vehicle stationary, engine off OR running)
reverse:                   157
ac_on (brief):               3    (oddly distinct — perhaps brief transient)
driving:                   155
stopped:                     6
```
Adds a new value (251 = engine off, was 254 in the T211240 reading) and
reveals the encoding's richness — at least 5 distinct states. Bit-level
decoding becomes interesting now.

### 0x385 byte 6 — confirms it's the odometer accumulator

```
all pre-driving:    0
driving:          215
stopped:          240    ← stays high after stopping, doesn't decay
```
Crucially, the value HOLDS at 240 during the `stopped` window — that's the
behavior of an **accumulator/odometer** (value doesn't decrement), not a
**speed** signal (would drop to 0 when stopped). Confirms our MEDIUM →
**HIGH-eligible** call.

### 0x551:0 (coolant) — full warmup arc captured

```
key_on_engine_off:   75°C  (engine had been recently warm)
ac_on:               94°C  (early in this session)
stopped:             ~99°C  (thermostat-regulated steady state)
```
First time we've seen the coolant signal reach **thermostat-regulated steady
state** (~95-100°C). This unlocks decoder validation: the
`plausible_max=130` bound is well-calibrated; the actual operating range
hovers comfortably within it.

### `0x29E:5` — promotes to HIGH

```
all stationary:       ~10
reverse:               66
ac_on:                249    ← spike when A/C kicked in!
driving:               48
stopped:                4
```
The 249 spike during `ac_on` confirms this is an engine-load-correlated
signal (A/C clutch adds load). Pattern fits **calculated load** or **engine
torque request** behavior.

### MAP signal `0x233:1` — engine-running confirmed

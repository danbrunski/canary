# One-time Mode 01 PID probe — 2026-07-22 (task 2.2)

Ran `tools/can_obd_probe.py --read-pids --dtcs` against the real vehicle in
both states task 2.2 asks for, on the bench-deployed Pi with the truck
idling in the driveway.

## Method

- Engine-running (idle, ~750-1200 RPM, coolant fully warm at 91°C).
- KOEO (`vehicle_state: ignition_only`, RPM 0, coolant still 91°C from the
  prior run).
- Walked the Mode 01 supported-PID bitmask (`0x00`/`0x20`/`0x40` banks),
  then queried every ECM-reported-supported PID once.

## Result: identical 41-PID supported set in both states

The ECM's supported-PID bitmask did not change between engine-running and
KOEO — same 41 PIDs both times (see raw output below). This ECM's bitmask
tops out at `0x4E`; it does not claim `0x60` (would unlock the next PID
bank), so PIDs ≥ `0x4F` are outside what a Mode 01 walk can even reach.

## Target list from task 2.2 — outcome

| PID(s) | What | Supported? |
|---|---|---|
| `0x5E` | Fuel rate | No — outside the ECM's advertised bank |
| `0x5D` | Injection timing | No — outside the ECM's advertised bank |
| `0x61-0x63` | Torque | No — outside the ECM's advertised bank |
| `0x55-0x58` | Secondary O2 trims | No — outside the ECM's advertised bank |
| `0x22`/`0x23`/`0x59` | Rail pressure | No — outside the ECM's advertised bank |
| `0x66-0x68` | (absent from registry) | No — outside the ECM's advertised bank |
| `0x45` | Relative throttle position | Already polled |
| `0x47` | Absolute throttle position B | **Yes** |
| `0x48` | Absolute throttle position C | No |
| `0x49` | Accelerator pedal position D | **Yes** |
| `0x4A` | Accelerator pedal position E | **Yes** |
| `0x4B` | Accelerator pedal position F | No |
| `0x4C` | Commanded throttle actuator | **Yes** |
| `0x5A` | Relative accelerator pedal position | No — outside the ECM's advertised bank |

None of the fuel-rate/injection-timing/torque/rail-pressure/secondary-O2
PIDs are supported — all expected on a 2008 VQ40DE port-injected gasoline
V6 (these are primarily direct-injection/diesel-oriented PIDs).

Four throttle/pedal-family PIDs the ECM *does* answer weren't previously
in the active poll set even though `MODE01_REGISTRY` (`obd_registry.py`)
already had full decoder entries for all six of `0x47`-`0x4C`: `0x47`,
`0x49`, `0x4A`, `0x4C`. Added to `can_obd_client.PID_DECODERS` (tiers
already correct in the registry: `0x47` medium, `0x49`/`0x4A`/`0x4C` fast
— picked up automatically via `_pid_channel_and_tier`'s `lookup()`).
`0x48`/`0x4B` confirmed genuinely unsupported by this ECM, left
undecoded-but-cataloged for vehicles that do support them.
